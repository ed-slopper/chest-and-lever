# Asset credits

Every file under `assets/` is listed here: path (relative to `assets/`), who made it, the licence, and where it
came from. Only our own work or openly licensed work; nothing taken from Levers and Chests, Notch's posts, or the
placeholders that game used (AGENTS.md section 13). `tools/check_assets.py` refuses an unlisted file.

| File | Made by | Licence | Source |
|---|---|---|---|

There are no asset files yet: every texture, voxel model, icon, portrait and sound in the game is generated by
our own code at start-up (`lac-rs/src/textures.rs`, `models.rs`, `icons.rs`, `audio.rs`), made for this project
by ed-slopper/heron and licensed CC BY 4.0 like our other assets (board row F7). The shader
(`lac-rs/assets/shaders/palette.wesl`) and the content files (`lac-rs/assets/content/*.ron`) are code and data
under the code's licence, MIT OR Apache-2.0.
